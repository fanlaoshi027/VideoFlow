# VideoFlow 目录 Excel 标准格式

VideoFlow 使用 `.xlsx` 作为 AI 目录识别结果的推荐交换格式。

## 最简格式

只需要两列：

| 页码 | 目录名称 |
|---|---|
| P01 | 有理数 |
| P02 | 数轴 |
| P03 | 相反数 |
| P19 | 有理数的加法 |

## 可选列

- 章节
- 小节
- 备注

软件会根据表头自动识别列顺序，不要求固定位置。

## 导入规则

1. 页码支持 `P1`、`P01`、`p19` 等形式。
2. 页码内部统一转换为整数保存。
3. 同一页码出现多次时标记为“重复页码”，不会直接覆盖。
4. 页码缺失或目录名称为空时，在导入预览中提示。
5. 用户确认后才写入教材库。

## 推荐 AI 工作流

书本目录截图 → AI OCR/整理 → 生成 XLSX → 人工快速检查 → 导入 VideoFlow。

MD 不是主交换格式；以后如有需要可以增加 CSV/JSON 导入。
